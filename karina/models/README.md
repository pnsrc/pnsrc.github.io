# Предоставленные модели Омска

Все 16 файлов скопированы из предоставленных пользователем GLB без перекодирования. Используется glTF 2.0, геометрия сжата Draco; PNG-текстуры встроены в каждый файл. У `russiaflagstep_a.glb` 26 mesh: шест и 25 взаимоисключающих кадров флага. Число треугольников в таблице суммирует все кадры; в игре одновременно видны шест и один кадр. Исходная STEP-анимация сохранена.

У остальных моделей один mesh и один материал. Исходные UV-каналы, цветовые карты, metallic/roughness и ambient occlusion сохранены. Два исходных материала (`muzteatr`, `omsk2gis`) используют запечённое освещение KHR_materials_unlit — загрузчик сохраняет эту настройку.

Собор и драмтеатр — самые подробные объекты, примерно по 25 тысяч треугольников. Павильоны и амфитеатр уже имеют лёгкую LOD-геометрию (69–191 треугольник). Дополнительное упрощение не требуется.

Файлы нормализуются с сохранением пропорций, центрируются по габариту и ставятся основанием на землю. Предельные размеры, поворот и координаты перечислены в `../omsk-layout.js`. Речной трамвай стоит на уровне воды. Размещение художественное, без воспроизведения реального порядка улиц.
